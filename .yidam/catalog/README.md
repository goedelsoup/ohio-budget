# catalog

The catalog tracks data sources. Corpus nodes cite catalog entries as shallow provenance
edges rather than embedding source metadata inline. See
[catalog conventions](../.vendor/prelude/guidelines/directories.md#catalog) for node format
and the corpus/catalog relationship.

Empty at genesis. Every domain claim in the seed corpus is therefore tagged `[inference]`
or `[open]` — no claim can be `[verified]` until the source it rests on is committed here.
Closing that gap is the first post-genesis phase.

## Adding a source

1. Create `catalog/<slug>.md` — use `author-year` for papers, a descriptive slug for
   datasets and APIs (`world-bank-gdp`, `openai-embeddings-api`).
2. Include: source name, type, location or access method, one-sentence description of
   what it contains, any access constraints.
3. Optionally add a `used-by` list of corpus node links for reverse traversal.
4. Link from any corpus node that draws on it: `[Author Year](../catalog/<slug>.md)`.

## Expected sources for this domain

The authorities that publish Ohio budget data do not share an identifier scheme, so each
gets its own catalog entry and corpus nodes cite them individually rather than citing a
generic "state budget data" source:

- **Legislative Service Commission** — per-agency budget analyses and stage-comparison
  documents. The authoritative record of what a line item stood at when a chamber acted,
  and therefore the primary source for `bill-version` and `appropriation` nodes.
- **Office of Budget and Management** — monthly financial reports and the state's audited
  annual financial report. The primary source for `expenditure` nodes and for reconciling
  appropriated against actual.
- **Ohio Revised Code** — the statutory basis for funds, revenue instruments, and
  distribution formulas. The primary source for `fund` and `revenue-source` nodes.
- **Controlling Board** — minutes and approved requests. The primary source for
  execution-level `budget-action` nodes.
