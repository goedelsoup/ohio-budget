# corpus

This corpus covers the Ohio state budget as a system of money flow, legislative process,
fiscal structure, and local incidence — modeled at the granularity of the appropriation
line item, across fiscal years 2010 to the present.

Each file is one node. Nodes are small and focused — one concept, one relation, one artifact,
or one open question. Every node must have at least one outgoing link.

See [corpus conventions](../.vendor/prelude/guidelines/directories.md#corpus) for authoring
rules, the authored/generated node distinction, and `[verified]`/`[inference]`/`[open]`
claim tags.

## Structure

Class definitions live at the top level as `<class>.ont.yml` and define what kinds of thing
exist. Instances live in a directory per class. Every class is aligned to UFO — each
definition carries a `ufo_type` field marking it as a kind, role, relator, event, or mode.
See [`.yidam/decisions/ontology.yml`](../decisions/ontology.yml) for why.

The load-bearing distinctions, which a reader should know before traversing:

- **`appropriation` is not `expenditure`.** The first is authority granted by a bill
  version; the second is money that actually left the treasury. Keeping them as separate
  classes makes the gap between them a traversal rather than a hidden field.
- **`line-item` is a durable identity, not a code.** Appropriation line item codes are
  renumbered and retired across the sixteen-year window. A `line-item` node persists
  through those events and carries `succeeds` / `superseded-by` edges across them.
- **`agency` is a kind; `actor` is a role.** The same agency requests money in one phase
  and spends it in another. The governor proposes in one month and vetoes in another.

## Claim confidence at genesis

The seed corpus carries no `[verified]` claims. Verification requires a committed primary
source linked from the node or its catalog entry, and [`.yidam/catalog/`](../catalog/) is
empty until the first extraction phase runs. Domain facts asserted at genesis are tagged
`[inference]` and are pending source verification; genuinely uncertain items are tagged
`[open]`. Dollar figures are stated at magnitude rather than to the cent for the same
reason — precision the corpus cannot source would be false precision.
