# skills

Domain-specific skills available to agents in this repository. Generic skills inherited
from yidam live in [`.vendor/prelude/skills/`](../.vendor/prelude/skills/); skills that
require knowledge of this domain's corpus or toolkit live here.

Skills are added when a repeatable procedure emerges from inquiry, not preemptively. The
procedures most likely to become skills in this domain are the two that a contributor
would otherwise perform by hand every time: resolving whether a line item in one biennium
is the successor of a differently-coded line item in an earlier one, and reconciling
appropriated authority against actual disbursement for a given line item and period.
Both are proposed and approved in
[`.yidam/decisions/proposals.yml`](../decisions/proposals.yml).
